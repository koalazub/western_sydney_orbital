Click or focus the canvas to use the in-game controls. A fresh Space press launches a paused lander and fires upward thrust while held. Space defaults to a four-times-power local practice boost. Use Details to select reference thrust and reset before comparing strategy runs. The always-visible flight readout shows actual speed and radial climb in metres per second, terrain-centre clearance in metres, and thrust acceleration in metres per second squared. Details and Export include force, torque, spin, target range, closing speed, sampled peaks and estimated fuel and damage. These are local rotating-frame measurements, not an STP-equivalent simulator. P runs or pauses the mission. WASD applies body-frame forces at offset nozzles: W and S forward and back, A and D left and right. E also fires up thrust at reference power; Q fires down thrust. Side thrust can roll or topple the lander through its real inertia and ground contacts. Manual thrust turns off the example controller. Releasing keys stops thrust, not velocity or spin. Animated exhaust streams in debug views point opposite the actual jet forces. This debug animation does not enter ship-camera RGB feeds. Hold Alt, called Option on macOS, with movement keys to move only the debug camera. Shift boosts debug movement only. Left drag orbits, right drag pans, and the wheel or trackpad pinch zooms the debug view. Keys 1 through 5 select debug views: orbit, first person, third person, free flight and overview. Keys 6 and 7 show the top and bottom ship sensors at 512 by 512 pixels with 8 bits per RGB channel and fixed exposure. Debug movement, pinch and wheel input do not change ship sensor mounts or optics. F frames the selected object. Period steps, T changes playback rate, and R opens reset confirmation. I opens the entity inspector and H opens help. M maximizes within the browser window. X or the Fullscreen button enters actual browser fullscreen; Escape exits fullscreen. Tab navigates game buttons, and Enter activates them. Space is reserved for lift, not button activation. Escape releases the mouse and canvas focus so Tab can leave the game. The advisory path preview does not control the lander.
